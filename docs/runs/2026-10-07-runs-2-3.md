# Run report: runs 2 and 3 of the next-runs plan (2026-10-07)

These are the first two runs of the [next-runs plan](2026-10-07-next-runs-plan.md). They retrain
nothing: they read the seed-42 models of the
[fine-tune-then-ASPIRE experiment](2026-10-07-sft-then-aspire.md) again.

- **Run 2** asks whether the fine-tune taught the material. The six students answer the 64
  held-out questions again, with up to 1024 new tokens instead of 256, and the 32B teacher scores
  the answers.
- **Run 3** builds a judge subset the teacher can separate. The teacher compares the two sides of
  each of the 127 judge pairs directly, in both orders. The seed-42 critics' recorded pair scores
  are then read again on the pairs it separates.

Each run's decision rule was written into the plan before it ran.

## Run 2: held-out answers at 1024 tokens

| Student | Teacher mean (95% interval) | Answers that ended within 1024 tokens |
|---|---|---|
| base | 7.906 [7.812, 7.984] | 64 of 64 |
| fine-tuned | 8.016 [7.969, 8.078] | 64 of 64 |
| control, local teacher | 7.938 [7.828, 8.031] | 64 of 64 |
| control, composite teacher | 7.922 [7.797, 8.016] | 64 of 64 |
| fine-tune + ASPIRE, local teacher | 7.984 [7.906, 8.047] | 63 of 64 |
| fine-tune + ASPIRE, composite teacher | 7.922 [7.797, 8.016] | 64 of 64 |

At 1024 tokens nearly every answer ends on its own, so the cap no longer distorts this measure. At
256 tokens, 50 to 61 of each student's answers were cut off.

**The rule.** The plan said the fine-tune taught the material if the fine-tuned student beat the
base by at least 0.2 in mean teacher score, with non-overlapping intervals.

**Reading under the rule: the fine-tune moved the representations without improving answers, by
the teacher's measure.**
- The gain is +0.11, half the bar.
- The intervals overlap: [7.97, 8.08] for the fine-tuned student and [7.81, 7.98] for the base.

**Context, outside the rule.** Paired over the same 64 questions, the gain is +0.109, with an
interval of [+0.016, +0.203]. So the fine-tune probably does improve answers slightly, by about
half the amount the plan set as meaningful.

**The ASPIRE students against their starting students** (paired differences):

| Comparison | Difference |
|---|---|
| control, local, against base | +0.03 [−0.06, +0.13] |
| control, composite, against base | +0.02 [−0.09, +0.13] |
| fine-tune + ASPIRE, local, against fine-tuned | −0.03 [−0.13, +0.05] |
| fine-tune + ASPIRE, composite, against fine-tuned | −0.09 [−0.25, +0.03] |

None differs. That is what the 1.2.0 trainer predicts, since it does not train the student toward
better answers ([#11](https://github.com/mcp-tool-shop-org/aspire-si/issues/11)).

**What this changes.** The 2026-10-07 experiment fine-tuned a student whose answers barely
improved, by the teacher's measure, while its hidden states moved about 30 times as far as ASPIRE
moves them. So its result is about how a large shift in representations, carrying a small gain,
affects the critic. It is not about a student that learned the material. The next-runs plan's
seed runs keep that framing.

## Run 3: the judge subset the 32B teacher separates

The teacher was shown both answers to each judge question, as A and B, and asked which is more
correct. Each pair was asked twice: once with the strong answer as A and once as B.
- A pair counts as separable when the teacher picks the strong answer both times.
- Every reply parsed (0 unparsed).

**Position bias.**
- With the strong answer first, the teacher picked A for **all 127 pairs**.
- With it second, it picked B, the strong answer, for **49**.

Its answer in the first order carries no information. Only the second order separates the pairs,
so "separable" here means "the teacher picks the strong answer even when it comes second". This
is the bias that asking in both orders was there to cancel. Over both orders it picked A 81% of
the time.

**Size.** The subset has 49 pairs across 35 questions.
- It shares only 15 pairs with the earlier 31-pair subset, which was defined by absolute scores.
- The two ways of asking the teacher pick largely different pairs.

**The rule.** The plan said the subset is read with the primary bar if it has at least 60 pairs
across at least 35 prompts.

**Reading under the rule: too small to decide.** The prompt count meets the bar; the pair count
does not.

**Description only, not a finding.** The seed-42 critics on these 49 pairs:

| Critic | Accuracy (95% interval, prompts resampled) |
|---|---|
| control, local teacher | 0.796 [0.660, 0.906] |
| fine-tune + ASPIRE, local teacher | 0.612 [0.455, 0.759] |
| control, composite teacher | 0.918 [0.830, 0.981] |
| fine-tune + ASPIRE, composite teacher | 0.653 [0.489, 0.792] |

They point the same way as the primary result on all 127 pairs. The subset is defined by the 32B
teacher alone. The composite critics are read on it too, though the composite teacher might
separate a different set.

## What comes next

- **Run 1, the seeds, goes ahead as planned.** The published result (the composite critic was
  worse after the fine-tune, 0.646 against 0.866) rests on one training run per condition. The
  seeds decide whether it holds. Run 2's reading changes how the result is framed, not whether
  it needs testing.
- **A stronger fine-tune is the next option, not yet approved.** That means more epochs or a
  higher learning rate, re-checked against run 2's bar before any ASPIRE runs on it. It would ask
  whether a fine-tune that does teach the material changes the critic differently.
